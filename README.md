# Documentación de La App:

-Esta app se dio origen el día 15/04/2025, El objetivo principal es crear la mejor aplicación
-sobre la provincia de san ignacio, junto a mi equipo. En este caso estamos contra el tiempo.
-Tenemos que avanzar rapido en el desarrollo y en la obtención de datos.
-Si en algun momento te falta claridad con la estructura del proyecto, descansa, piensa y retomalo.
-Vamos a aplicar clean architecture en el desarrollo de esta app y código limpio con principios SOLID.
-Si quiero otro idoma voy a tener que poner otro parametro donde este en otro idioma y con BLoc osea el Gestor de estado, ver en la UI en que idioma esta y segun eso cambiar de parametros.

# Algunas recomendaciones para este proyecto:

1-Antes de meter una funcionalidad al proyecto, crea un mini proyecto provando esa funcionalidad, luego eso lo implementas en la app.
2-Siempre guarda copias de código cuando hagas otro que aun no sabes si va funcionar mejor o peor.
3-Intenta siempre crear código limpio, para produción.
4-Prueba constantemente la app en el emulador.
5-El objetivo es hacer la app cueste lo que cueste de cualquier manera.
6-Cualquier problema de inconpatibilidad, hay que leer documentación y evaluarlo mucho.
